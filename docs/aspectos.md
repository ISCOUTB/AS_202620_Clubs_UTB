# Aspectos de Calidad y Trazabilidad

Cada fila recorre la cadena **aspecto $\rightarrow$ requisito $\rightarrow$ elementos C4 $\rightarrow$ ADR $\rightarrow$ código $\rightarrow$ pruebas $\rightarrow$ evidencia**. Las pruebas se ejecutan con:

```bash
cd backend && PYTHONPATH=src JWT_SECRET=test DATABASE_URL=sqlite:///./test.db pytest tests/ -v
```

En la última ejecución local pasaron las **38 pruebas** de la suite. Los escenarios citados están definidos en la [Sección 10 de arc42](arc42/10_requisitos_de_calidad.md).
