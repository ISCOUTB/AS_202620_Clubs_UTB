# AS_202620_Clubs_UTB

Sistema para la gestión de clubes estudiantiles de la Universidad Tecnológica de Bolívar.

## Problema
En la Universidad Tecnológica de Bolívar, existen gran variedad de clubes abiertos para los estudiantes, sin embargo, aún no existe una herramienta destinada para los grupos
donde ellos puedan hacerse ver y ofrecer las maravillosas experiencias. Este problema no solo afecta a los integrantes del club, sino que también a los posibles interesados ya que 
es de suma importancia que dicho información llegue al mayor numero de personas posible

## Tecnologías
- Framework: Flutter
- Base de datos: postgres
- Api: fastapi
